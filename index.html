Частые вопросы

Нет. Это стандартное предупреждение Windows SmartScreen для новых программ без дорогой цифровой подписи. Нажмите «Подробнее» → «Выполнить в любом случае». Программа полностью безопасна и не содержит вредоносного кода.
Это стандартное предупреждение Gatekeeper для приложений без платной подписи Apple. В Finder откройте папку «Программы», кликните по приложению правой кнопкой (или Control + клик) → «Открыть» → подтвердите «Открыть» в появившемся окне. Это нужно сделать только один раз, дальше программа будет открываться обычным двойным щелчком.
Некоторые антивирусы настороженно относятся к любым программам, которые могут записывать экран и микрофон — это нормальная защитная реакция, а не признак реальной угрозы. Добавьте программу в исключения антивируса.
Убедитесь, что в программе включена галочка «Захватывать звук системы». Если звука всё равно нет — проверьте, что звук воспроизводится через стандартное устройство вывода системы (обычные динамики/наушники по умолчанию), а не через специфичное аудио-ПО (виртуальные аудиокабели, эксклюзивный режим устройства). На Mac системный звук записывается начиная с macOS 13 (Ventura) и новее.
Windows: Параметры → Конфиденциальность и безопасность → Микрофон. Mac: Системные настройки → Конфиденциальность и безопасность → Микрофон. В обоих случаях доступ приложению к микрофону должен быть включён.
Запись в 4K или 60 кадров/сек требует достаточно мощного процессора. Если компьютер слабый — выберите в настройках качество 1080p при 30 кадрах/сек.
В папку «Видео → ScreenRecorderHD» на вашем компьютере. Открыть её можно прямо из программы кнопкой «Открыть папку с записями».
После оплаты вы получите лицензионный ключ на почту. При первом запуске программа попросит вставить его — просто скопируйте ключ из письма целиком.
